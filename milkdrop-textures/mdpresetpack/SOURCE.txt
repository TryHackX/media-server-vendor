Four textures presets of the packs name that no repository on GitHub has.

portal1.jpg, portal2.jpg, AbalonyStosich.jpg, noise64.png
  used by: Flexi's "dawn has broken - pallet by live portal" and "clock head meshuggahn
  portalian…" (portal1, portal2), the digital-art.org AbalonyStosich preset, and "no rules, no
  judgement, only hate" (noise64, beside chloemall and chloemallCornerMask).

Source:   SourceForge project "mdpresetpack" (maintainer ravermeister85), archive mdpresets.zip
          dated 2019-10-22, 182 673 276 bytes, entries 52kpresets/textures/<name>.
          https://sourceforge.net/projects/mdpresetpack/files/mdpresets.zip/download
          Only these four entries were fetched, with byte-range requests (the archive also holds
          an uninstall.exe, a .bat and a .jar, none of which was downloaded); each entry passed
          its CRC check. noise64 is also at
          https://archive.org/download/most-odd-named-presets/Canonical_MilkDrop_Presets.zip/presets%2Fnoise64.dds
          (byte-identical).
